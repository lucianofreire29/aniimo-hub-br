# Aniimo Brasil

Portal brasileiro de informações, ferramentas e comunidade sobre **Aniimo**.

## Objetivo

O **Aniimo Brasil** será uma plataforma em português com catálogo de Aniimos, formas, atributos, elementos, habilidades, evoluções, habitats, guias e outras ferramentas para a comunidade.

## Stack inicial

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Neon PostgreSQL

## Status

Projeto em desenvolvimento.
